# Elevator Hub

Professional B2C website for elevator maintenance, repair and emergency services in Islamabad & Rawalpindi.

## Features
- Responsive mobile-first design
- Service showcase for maintenance, repair, emergency support and installation
- Click-to-call emergency line
- WhatsApp service request flow
- Customer service request form
- FAQ accordion
- Sticky navigation and mobile menu
- SEO title, description and responsive metadata
- No build tools or dependencies required

## Run locally
Open `index.html` in a browser. The site is static HTML/CSS/JS and can be deployed directly with GitHub Pages.
